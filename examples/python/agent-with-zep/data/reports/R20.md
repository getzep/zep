Field service report R20, dated 2026-09-10, prepared by Colm Brennan.

Fernway occlusion alarms occur with no actual occlusion in some home-care
settings. The complaints are tracked as QI-1062, severity low, status open. No
patient harm has been reported.

The pattern suggests a sensitivity threshold issue in the occlusion detection
algorithm rather than a hardware fault. Nursing staff clear the alarms and restart
therapy, which adds burden but does not interrupt delivery for long. Field Service
will keep collecting reports to size the problem.
