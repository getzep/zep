Engineering test report R18, dated 2026-08-28, prepared by Ravi Kulkarni.

Firmware 0.9.4 is a candidate fix for QI-1068. In 200 test runs it reduced
alarm-forwarding dropouts through the WM-4 wireless module from 3% to 1%. The
target is 0%.

QI-1068 remains open. The next iteration will address the remaining dropout cases,
which correlate with channel congestion in the test environment. A verification
protocol for the final candidate is in review.
