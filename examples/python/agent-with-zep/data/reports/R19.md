Risk review R19, dated 2026-09-04, prepared by Hannah Cole.

The 2026-11-16 Lyric 350 launch date is at risk because QI-1068 is open and the FDA
response to the additional-information request is due 2026-10-28.

The WM-4 wireless module is single source from Tamsin Electronics; no second
source is qualified. If the fix requires a hardware revision, the launch date will
move. The team should hold the November date only if firmware 1.0 verification
reaches zero dropouts with margin for the FDA response.
