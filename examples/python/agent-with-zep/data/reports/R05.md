Engineering test report R05, dated 2026-04-10, prepared by Grace Lindholm.

Firmware 2.3.1 adds a drift-compensation algorithm for the FS-20 flow sensor on the
Aster 410.

Bench testing at 25 °C on 12 units showed all units within ±2% of the programmed
rate. The test did not cover low ambient temperature, which remains an open test
gap because the complaint pumps were deployed in cooler rooms.

Firmware 2.3.1 was released to the field on 2026-04-24. Field performance data
should be monitored to confirm effectiveness under real conditions.
