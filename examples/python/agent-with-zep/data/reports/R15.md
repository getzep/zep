Regulatory update R15, dated 2026-07-30, prepared by Julien Moreau.

The FDA sent an additional-information request for the Lyric 350 510(k). The
request concerns wireless alarm-forwarding performance.

The response is due 2026-10-28. The 510(k) review is on hold until Pemberline
responds. The Lyric 350 is NOT cleared. The response will include the QI-1068
test data and the corrective-action plan once the firmware fix is verified.
